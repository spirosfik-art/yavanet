# Δείκτης Yavanet (מדד יוונט)

Ένα αρχείο ανά μήνα, π.χ. `2026-10.json`. Μόλις υπάρξει το πρώτο αρχείο, εμφανίζεται αυτόματα η σελίδα /madad/ και το κουμπί «📊 מדד יוונט».

```json
{
  "month": "2026-10",
  "areas": [
    { "he": "קולונאקי", "en": "Kolonaki", "sale": 6200, "saleChg": 1.2, "rent": 17.5, "rentChg": 0.8 }
  ],
  "note": { "he": "…", "en": "…" }
}
```

- sale: μέση τιμή πώλησης €/τ.μ.
- rent: μέσο μηνιαίο ενοίκιο €/τ.μ.
- saleChg / rentChg: μεταβολή % σε σχέση με τον προηγούμενο μήνα (προαιρετικά)
- note: 1–2 προτάσεις «τι άλλαξε αυτόν τον μήνα» (προαιρετικά)
